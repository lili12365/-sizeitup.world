Practical estimating tips

Use people carefully. Human height is useful, but posture and perspective can trick you.

Convert to door units. For anything taller than a person, ask how many 2 m doors could stack inside it.

Look for category clues. Furniture, appliances, sports objects, animals, and street fixtures follow different size conventions.

Trust the correction. A bad guess is valuable if you remember the anchor it creates.

How to improve

Build a personal reference library.

The fastest way to improve at a size guessing game is to collect a few dependable anchors instead of trying to memorize every answer. Start with the objects you see every day: a phone is around 15 cm tall, a kitchen counter is close to 90 cm, and an interior door is usually near 200 cm. When a new prompt appears, compare it with one of these references before moving the slider.

After each reveal, notice the direction of the error. If you guessed too small, ask whether the object was longer, taller, or wider than the reference you used. That small correction is more useful than the score alone because it gives you a mental rule for the next round.

Size It Up FAQ

How do you play Size It Up?

Look at the object, estimate its size in centimeters, move the slider, and lock in your guess. The game then shows the real measurement, accuracy, points, and a useful comparison.

What exactly am I estimating?

The game asks for height in centimeters. For animals, height means shoulder height. For long objects such as rackets, the displayed number is the object's length.

How many rounds are in the daily game?

Daily 5 has five questions. Everyone receives the same date-based set, and the set changes automatically on the next day.

Where do the measurements come from?

Measurements use common residential dimensions, regulation standards, typical appliance sizes, and average object proportions as practical visual anchors.
