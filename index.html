How the game works

A quick size guessing game with a useful answer.

Size It Up turns everyday objects into short, repeatable scale puzzles. You see a prompt such as a door, phone, animal, or street fixture, then estimate its height or length in centimeters. The goal is not to remember trivia. It is to make a clear prediction, compare it with a real-world reference, and leave with a better mental ruler.

Rules and scoring

Guess the size, lock it in, then learn from the gap.

Each Daily 5 session contains five objects. Move the slider until your estimate feels right, then select Lock in guess. Before submitting, the game keeps the answer hidden so your estimate remains a genuine test of visual intuition. After you submit, you see the actual measurement, your accuracy, the point value, and a short comparison that helps the number stick.

Scoring rewards closeness rather than speed. Accuracy begins at 100% for a perfect estimate and decreases based on the relative difference between your guess and the real answer. The point value is accuracy multiplied by 10, so an 88% estimate earns 880 points. A result that is far away is still useful: the correction shows which familiar object can become your next scale anchor.

Why a daily reset makes the game better

One shared challenge. The date-based set gives everyone playing Daily 5 the same five prompts, making scores easy to compare without making the game competitive.

A small habit. Five rounds are short enough to finish in a few minutes, while the daily pause gives each answer time to become a durable reference.

Fresh categories. The object library moves between home scale, sports, living things, vehicles, city objects, and much larger landmarks.

Practice stays open. When you want more than five questions, Explore mode lets you continue with the full library without changing the next Daily 5 set.

Size It Up FAQ

How is the score calculated?

Your accuracy starts at 100% and drops according to the percentage difference between your guess and the real measurement. Points are accuracy multiplied by 10, so a 92% guess earns 920 points. This means a close guess is rewarded even when it is not exact, and a perfect guess earns the maximum 1,000 points.

Is Size It Up free?

Yes. Size It Up is a free size guessing game with five daily rounds, and you do not need an account, payment, or sign-up to play. Your browser can open the game directly, and the Explore mode is also available for extra practice.

Does Size It Up reset daily?

Yes. The Daily 5 puzzle set is selected from the current date, so a new shared set appears automatically each day. Your five-round session starts over with that new set, while Explore mode remains available for unlimited practice between daily resets.
